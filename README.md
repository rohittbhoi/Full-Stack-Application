# Full Stack Application: ReactJS + Spring Boot CRUD App

A comprehensive full-stack application showcasing CRUD (Create, Read, Update, Delete) operations, built using **ReactJS** for the frontend and **Spring Boot** for the backend.

## Features

- CRUD operations for managing employee data.
- RESTful API built with Spring Boot.
- User-friendly interface designed using ReactJS.
- Fully responsive design with reusable components.
- Integration between frontend and backend via API endpoints.

---

## Prerequisites

Before setting up the project, ensure you have the following installed:

1. **Java** (version 8 or higher)
2. **Node.js** (version 16 or higher) and npm/yarn
3. **Maven** (version 3.6 or higher)
4. **Git** (latest version)
5. A compatible **IDE** (e.g., IntelliJ IDEA, Visual Studio Code)
